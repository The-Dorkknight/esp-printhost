## Board facts confirmed so far

- **ESP32-S3-Zero type board:** flash detected as 4 MB (the image is built for 2 MB, which works on any
  ESP32-S3; the warning about it at boot is harmless). Colour LED on GPIO21 and TX/RX on GPIO43/44 per
  Waveshare's documentation.
- **SKR Pico:** Klipper on UART0 GPIO0/GPIO1 at 250000 baud answers as expected. Its on-board RGB LED is a NeoPixel on gpio24, GRB order (confirmed: colours came out right).
